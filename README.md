## Study structure

Each major area is a numbered directory. Topic names are kept aligned with Notion so the two repositories can be navigated together.

Every topic is intended to contain:

1. Concept and intuition
2. Detailed technical explanation
3. Practical Python / AI-engineering programs
4. AI/LLM/RAG production relevance
5. Common mistakes and interview traps
6. Complexity, performance and scalability where relevant
7. Interview questions with answers
8. Quick revision notes

The final interview sections consolidate cross-topic questions, coding practice, system design, behavioral preparation, mock interviews and revision.

## Core interview progression

**Python → Mathematics → ML → Deep Learning → Transformers/LLMs → LLM Applications → RAG → Agents → Fine-tuning → Infrastructure → Evaluation → Security → MLOps → Data Engineering → System Design → Projects → Interview Questions → Mock Interviews**

FastAPI is maintained as a separate engineering track because it is a core implementation skill for production AI APIs.

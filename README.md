## Repository convention

**Top level = major interview section**  
**Section directory = Notion top-level page**  
**Numbered child directory = Notion nested topic/page**  
**README.md = navigation/content entry point**

There is intentionally **no separate INDEX.md**. The root README is the roadmap; each section README is its navigation page.

## FastAPI

`fastapi-for-ai-engineering/` is a separate AI-engineering API track and is not mixed into the 18 core sections.

## Study method

For each topic, the eventual content structure is:

- Concept and intuition
- How it works
- Practical Python/AI programs
- AI-engineering examples
- Common mistakes and interview traps
- Performance/scalability considerations
- Interview questions and answers
- Coding exercises where applicable
- Quick revision notes
